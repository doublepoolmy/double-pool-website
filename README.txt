DOUBLE POOL WEBSITE — QUICK START
================================

Files:
- index.html  : Main website content
- style.css   : Layout, colours and responsive design
- script.js   : Mobile menu and enquiry form settings

PREVIEW ON YOUR COMPUTER
1. Extract the ZIP file.
2. Open the "double_pool_website" folder.
3. Double-click index.html. It opens in your web browser.
4. Internet connection is needed for the sample pool photos and Google Fonts.

BEFORE PUBLISHING
1. Open script.js in Notepad or another text editor.
2. Find: const COMPANY_EMAIL = "";
3. Add the real company email between the quotation marks.
4. Replace sample photography with your own completed project photos when ready.
   The current gallery images are illustrative sample photography, not verified company projects.
5. Add the actual company phone, WhatsApp, address and service area when these are confirmed.

FREE HOSTING WITH GITHUB PAGES
1. Create/sign in to a free account at https://github.com
2. Create a new public repository, for example: double-pool-website
3. Upload index.html, style.css and script.js to the repository root (not inside another folder).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish. Your free address will look like:
   https://YOUR-USERNAME.github.io/double-pool-website/

DOMAIN
You do not need to buy a domain to publish on the free GitHub Pages address.
If you already own a domain, you can connect it later. First identify the registrar
from the purchase receipt or domain renewal email. Do not change DNS records until
you know whether the domain is also being used for company email.

NOTES
- No paid website builder is used.
- GitHub Pages free hosting requires a public repository for this setup.
- Contact form uses the visitor's email app (mailto); it is not a database-backed form.
- No company address, phone, email, years of experience, certifications or testimonials
  have been invented in this template.
